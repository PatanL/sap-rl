## Sleeping Pill placement

The shop constructs its own event context, then delegates to the common `battle_phase_hurt_and_faint`. For the `shop` phase this flushes post-removal events immediately. The flush orders simultaneous faints by attack, resolves native summons before equipment for a given owner, and uses the same fixed-slot insertion as battle. No engine edits were made for this check. A compatible row means at least one native prefix replay could produce a layout allowed by the recorded actions and real endpoint. It is much weaker than a unique position. The stronger column requires actual new UIDs and identical occupied **new slots** across all possible immediate layouts. It need not distinguish the order of identical tokens. For the positional comparison, later BoardOrders were treated as commands. Their UID set identifies membership but their destination fields cannot reveal the earlier positions. The check reconstructed post-Pill membership backward from the next such list or the terminal board, enumerated the possible five-slot layouts, and propagated them forward through the later logged actions. Both vacancy-shift directions were admitted rather than guessing which one occurred on a later insertion. A second Pill before the anchor, an unnamed earlier purchase, or an unresolved prefix can preclude a claim. The native replay used up to 200 seeds and compared surviving UIDs, new species where known, and physical slots. [Method](shop/pill.py)

As an independent implementation test, the native shop matched the stated insertion rule on **560/560** constructed boards covering all five target slots and all 16 other-occupancy patterns for Deer, Sheep and Spider with and without Mushroom, and Mushroom Fish. A second set pilled Hedgehog to kill Mushroom Deer and Sheep simultaneously on **120** layouts/orderings, including both choices of which pet had higher attack. All **120/120** matched the separate attack-order and push-direction calculation. These fixtures test the Python implementation of the proposed rule; they supply no additional real-game evidence.
